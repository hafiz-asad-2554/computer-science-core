# Computer Science Core

Welcome to my **Computer Science Core** repository.

This repository contains the **academic and practice code** I’ve written throughout my **BS Computer Science** degree. The code here reflects my learning journey — from understanding basic programming concepts to implementing data structures, algorithms, web applications, and introductory AI/ML models.

This is **not a showcase of production-level software**. Instead, it’s a structured record of how I learned core computer science concepts through hands-on implementation.

---

## 🎯 Purpose of This Repository

The main goals of this repository are to:

- Track my progress as a Computer Science student
- Practice implementing theoretical concepts in code
- Build strong fundamentals across core CS subjects
- Maintain a clean, subject-oriented reference for revision and future work

Some code is simple by design, especially in earlier folders, because it was written while learning the basics.

## 📚 Subjects Covered

All work is organized **by subject**, not by semester:

- **01-programming-fundamentals-cpp**  
  Basics of programming using C++ (loops, conditions, functions, arrays)

- **02-object-oriented-programming-java**  
  Core OOP concepts such as classes, objects, inheritance, polymorphism

- **03-python-programming**  
  Python scripts, logic building, and problem-solving

- **04-data-structures**  
  Linked lists, stacks, queues, trees, graphs, and related problems

- **05-design-and-analysis-of-algorithms**  
  Sorting, searching, greedy algorithms, dynamic programming, and complexity analysis

- **Other core subjects**  
  Databases, Operating Systems, Computer Networks, Web Development, Artificial Intelligence, Machine Learning, and Data Science
