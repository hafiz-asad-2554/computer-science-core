# Programming Fundamentals (C++)

This folder contains my code from the Programming Fundamentals course. It was my first proper introduction to coding (unless you count HTML), so we started with C++.

## Contents

- **programs/**: Small practice codes for labs and concepts (loops, arrays, pointers, etc.).
- **projects/**: A few larger "projects" we had to do at the end of the semester.

## Concepts Covered

- Variables & Data Types
- Control Structures (If-else, Loops)
- Arrays (1D & 2D)
- Functions
- Pointers (still confusing tbh)
- Structures
- File Handling

## Build

I use `g++` to compile these.

```bash
g++ programs/01_hello_world.cpp -o out
./out
```
