# Object Oriented Programming (Java)

After struggling with pointers in C++, Java felt like a blessing (mostly). This course was all about Classes, Objects, and the 4 pillars of OOP.

## Contents

- **programs/**: Concept practice.
- **projects/**: Semester projects.

## Concepts

- Classes & Objects
- Inheritance & Polymorphism
- Abstraction & Interfaces
- Exception Handling
- File I/O (Scanner, BufferedReader)
- Collections Framework (ArrayList, HashMap)
- Multithreading (Basics)

## Build

I use `javac` and `java`.

```bash
javac programs/HelloWorld.java
java programs/HelloWorld
```
