# Software Testing

## V-Model

Verification and Validation.

## Levels using PyTest / JUnit logic (Concepts)

1. **Unit Testing**: Testing individual components.
2. **Integration Testing**: Testing combined parts.
3. **System Testing**: Testing the whole.
4. **Acceptance Testing**: User sign-off.

## Types

- **Black Box**: No knowledge of internal code.
- **White Box**: Validating internal logic.
