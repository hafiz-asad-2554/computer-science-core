# Requirement Engineering

The process of defining, documenting, and maintaining requirements.

## Types

1. **Functional Requirements**: What the system should do (e.g., "System shall send an email").
2. **Non-Functional Requirements**: How the system performs (e.g., "System shall load in < 2 sec").

## SRS (Software Requirement Specification)

A document that describes the features and behavior of a system.
